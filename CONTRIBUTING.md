# Guía para contribuir

Gracias por ayudar a construir conocimiento revisable, no solo una colección de opiniones.

## Crear una propuesta

1. Elige el dominio y el siguiente identificador disponible.
2. Copia [la plantilla](methodology/proposal-template.md) a `dominio/proposals/`.
3. Nombra el archivo como `ID-titulo-corto-en-ingles.md`; el contenido puede escribirse en español.
4. Explica el problema, los supuestos, los beneficios, los riesgos, la evidencia y las incertidumbres.
5. Añade la propuesta al [índice](INDEX.md).

## Estándar de evidencia

- **Verificada:** respaldada por una fuente primaria o revisión fiable, citada de manera suficiente para localizarla.
- **Inferida:** conclusión razonable a partir de evidencia o premisas explícitas, pero no demostrada directamente.
- **Especulativa:** hipótesis o posibilidad útil que aún no tiene apoyo suficiente.

Las críticas son parte del registro. No se eliminan por discrepar: se responden, se incorporan o se documenta por qué no cambian la propuesta.

## Cambios

Usa mensajes de cambio claros. Una contribución debe poder revisarse de forma independiente y no debe presentar una inferencia como un hecho verificado.
