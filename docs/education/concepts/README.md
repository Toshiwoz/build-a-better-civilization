# Concepts

**Scope:** Education — Concept layer  
**Purpose:** Concise, stable canonical documents that define the foundational ideas of the education domain.

## What belongs here

- High-level definitions of core educational ideas
- Cross-cutting principles that govern program and curriculum design
- Stable reference points for other documents to link against

These docs are intentionally brief and structural. Detailed proposals, evidence, and discussion live in [`../proposals/`](../proposals/).

## Naming convention

Concept documents follow the pattern `EDU-NNN-title-kebab-case.md`. IDs are never reused.

## How to add a concept doc

1. Pick the next available `EDU-NNN` ID. Check the table above and [EDU-ARCH-002 Content Map](../architecture/EDU-ARCH-002-content-map.md) for existing IDs to avoid collisions.
2. Copy the metadata header from an existing concept doc.
3. Keep content concise and structural — link to proposals for detail.
4. Add a row to the table above.
5. Open a PR and link any related Issues.
