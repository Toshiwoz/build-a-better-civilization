# EDU-003 — Learner Outcomes Framework

**Type:** Concept  
**Status:** Draft  
**Scope:** Education — Global  
**Owner:** Community  
**Last updated:** 2026-07-21

## Summary

A shared framework for defining, categorizing, and evaluating what learners should be able to do, think, and embody at different stages of their education. This framework bridges purpose (EDU-001) and curriculum design.

## Framework dimensions

Outcomes are grouped into four dimensions:

| Dimension | Description | Example outcomes |
|-----------|-------------|-----------------|
| **Cognitive** | Knowledge, reasoning, judgment | Critical analysis, historical understanding, scientific thinking |
| **Practical** | Skills applicable in real contexts | Self-care, cooperation, basic economics, civic participation |
| **Character** | Dispositions and values | Curiosity, responsibility, ethical sensitivity, resilience |
| **Relational** | Capacities for living with others | Empathy, conflict resolution, communication, teamwork |

## Progression model

Outcomes are organized by autonomy level rather than age or grade:

- **Level 1 — Supported:** Learner needs guidance; develops foundational skills.
- **Level 2 — Guided:** Learner works with scaffolding; applies skills in familiar contexts.
- **Level 3 — Independent:** Learner applies skills across contexts with minimal guidance.
- **Level 4 — Mentor:** Learner supports others and contributes to improving the system.
