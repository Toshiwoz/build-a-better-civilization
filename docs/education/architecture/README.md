# Architecture

**Scope:** Education — Architecture layer  
**Purpose:** Documents that describe the structure and organization of the education knowledge base itself.

## What belongs here

- System and information architecture overviews
- Content maps showing what exists and how it connects
- Structural decisions about how the education domain is organized

These docs describe the *system*, not the *content*. Educational ideas live in `concepts/` and `proposals/`.
