# Education

This section is the central knowledge base for the education domain of the Build a Better Civilization project. It collects proposals, concepts, evidence, and design documents about the purpose, organization, and practice of education.

## Read this first

1. [EDU-001 — Purpose of Education](concepts/EDU-001-purpose-of-education.md)
2. [EDU-002 — Principles of Learning](concepts/EDU-002-principles-of-learning.md)
3. [EDU-ARCH-001 — System Overview](architecture/EDU-ARCH-001-system-overview.md)

## If you are…

**A new contributor**
→ Read [EDU-001](concepts/EDU-001-purpose-of-education.md), then browse [open proposals](proposals/) and [CONTRIBUTING.md](../../CONTRIBUTING.md).

**A curriculum designer**
→ Start with [EDU-003 — Learner Outcomes Framework](concepts/EDU-003-learner-outcomes-framework.md), then explore [proposals/](proposals/) and [programs/](programs/).

**A teacher or operator**
→ See [teaching/](teaching/) and [operations/](operations/). Review [EDU-002 — Principles of Learning](concepts/EDU-002-principles-of-learning.md) first.

## Folder structure

```
docs/education/
├─ concepts/       High-level canonical definitions (EDU-001, EDU-002 …)
├─ architecture/   Structure and content-map docs (EDU-ARCH-001 …)
├─ proposals/      Full proposals with evidence, discussion, and decisions
├─ programs/       Curriculum and program design
├─ teaching/       Pedagogy, methodology, teacher requirements
├─ tools/          Tooling principles and approved tools
├─ operations/     Implementation, rollout, metrics
├─ references/     Glossary, bibliography, external links
├─ evidence/       Education-specific evidence and literature reviews
├─ discussions/    Transversal discussion threads
└─ decisions/      Recorded decisions for this domain
```
